# 🎴 Anime Persona Judge

An AI-powered web application that judges your anime taste, assigns you a "Spirit Character," and delivers a brutal roast based on your Top 9 favorites.

## 🚀 Features
- **AI Analysis:** Uses Google Gemini 3 Flash to evaluate your taste.
- **Spirit Character:** Finds the character that best represents your personality using the Jikan API.
- **Personality Snapshot:** Generates a unique psychological profile based on your watch list.
- **Hall of Fame:** A global leaderboard of judged users, sorted by their "Taste Score."
- **Persistent Storage:** Powered by Supabase to keep track of every judgment.

## 🛠️ Tech Stack
- **Frontend:** [Streamlit](https://streamlit.io/)
- **AI Model:** [Google Gemini 3](https://ai.google.dev/)
- **Database:** [Supabase](https://supabase.com/)
- **Anime Data:** [Jikan API (Unofficial MyAnimeList API)](https://jikan.moe/)
- **Language:** Python 3.x
